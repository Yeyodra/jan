## Context

### Original Request
User asked whether an LLM/agent can generate Excalidraw diagrams via prompt and integrate that into the Jan project. After deep investigation, three findings reshaped scope:

1. Jan already has Excalidraw fully integrated (`@excalidraw/excalidraw@0.18.1`, full canvas system, AI tools T18 series).

User chose: **Layered approach** — keep T18 (canvas-level tools) and add mcp_excalidraw (element-level tools) on top. Single entry point: prompt bar at `/canvas/$canvasId`. No chat-side integration.
