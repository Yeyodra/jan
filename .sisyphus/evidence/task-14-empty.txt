Decision rationale (for the audit trail)
----------------------------------------
mcp_excalidraw's import_scene handler at
  src-tauri/resources/mcp_excalidraw/dist/index.js:1400-1402
throws "No elements found in the import data" whenever the import data
yields zero elements. We could swallow that error (the `failed` outcome
branch already handles it gracefully) but the noise pollutes telemetry on
every empty-session start. We therefore short-circuit BEFORE the wire call
when elements is empty: no callTool invocation, no error log — only a
debug-level "empty canvas" trace so test harnesses can still confirm "sync
was attempted".

Verdict
-------
PASS — empty canvas does not call import_scene; outcome is skipped/empty-canvas;
       no error path triggered.
